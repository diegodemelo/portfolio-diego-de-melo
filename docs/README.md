# Documentação do Portfólio

Esta pasta reúne documentação operacional, evidências de QA e
manifests históricos do projeto.

## Estado atual

O ponto principal de retomada é:

- `ESTADO_ATUAL.txt`

Esse arquivo representa o estado vigente do portfólio, incluindo
publicação, versionamento e situação de QA.

## Escopo

- `ESCOPO.txt`

Esse documento registra o escopo original da Fase 1.

Alguns itens inicialmente classificados como fora do escopo foram
implementados em fases posteriores. Em caso de diferença entre o
escopo histórico e o estado real atual, prevalece
`ESTADO_ATUAL.txt`.

## Histórico de QA

Os documentos abaixo representam a situação existente quando cada
fase foi executada:

- `QA_FASE_1.txt`
- `QA_FASE_2_VISUAL.txt`

As ressalvas históricas desses relatórios foram tratadas em etapas
posteriores. A situação vigente está consolidada em
`ESTADO_ATUAL.txt`.

## Manifests

- `MANIFEST_SHA256_v0.2.0.txt`
- `MANIFEST_SHA256_v0.3.0.txt`

Os manifests são evidências históricas das versões correspondentes
e não devem ser reescritos após a versão ter sido selada.

## Ordem recomendada de leitura

1. `README.md` na raiz do repositório;
2. `docs/ESTADO_ATUAL.txt`;
3. `docs/ESCOPO.txt`;
4. relatórios históricos de QA;
5. manifest da versão necessária.

HISTÓRICO não substitui ESTADO ATUAL.
